# LuckBlock

> [!NOTE]
> This addon has moved into the [mcx-example-addon](https://github.com/RuanhoR/mcx-example-addon) monorepo and is now maintained there as a pnpm workspace package. This repository is kept for history.

> A simple, base on [mcx](https://github.com/RuanhoR/mcx-core), run on minecraft bedrock LuckBlock addon

## Usage

Download from [Github release](https://github.com/RuanhoR/LuckBlock/releases) or self-build

```bash
git clone https://github.com/RuanhoR/LuckBlock.git

cd LuckBlock
# Plase install nodejs and pnpm
pnpm build
```
